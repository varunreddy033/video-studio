# Asset library (in git)

Put your music and sound effects here. Video Studio reads this folder on every Check and every render, so a new
file is usable as soon as it is on the Mac (`git pull`). The **folder name is how a file is found**; the file
name can be anything.

```
assets/library/
  music/<mood>/<track>.mp3     background music, grouped by mood
  sfx/<kind>/<sound>.wav       sound effects, grouped by kind
```

## How to upload (GitHub website)

1. Open your own repository on GitHub (the private one you push to) and go into `assets/library/music/calm` (or any folder below).
2. **Add file -> Upload files**, drop the files in, **Commit changes**.
3. On the Mac: `cd ~/youtube-pipeline && git pull origin main`, then press Check again.

GitHub's website takes files up to 25 MB each. MP3 is best for music (a 3-minute track is 3-7 MB); `.mp3 .wav
.m4a .aac .ogg .flac` all work. To add a new mood or kind, type `newname/` in front of the file name while
uploading: that creates the folder.

## Music: `music/<mood>/`

| Folder | Put here |
|---|---|
| `calm` | soft, slow beds for explainers |
| `uplifting` | positive, light, motivational |
| `tense` | suspense, building pressure |
| `dark` | ominous, serious, crime, crashes |
| `mystery` | curious, investigative |
| `epic` | big orchestral, trailers, reveals |
| `tech` | electronic, synth, modern |
| `emotional` | piano, strings, human stories |

- Only tracks of **1 minute or longer** are used (shorter ones are ignored; the track loops if the video is longer).
- **What I need to start:** 2-3 tracks in each mood you will actually use. One mood with one track is enough to test.
- Name files `Track Name - Artist.mp3`: the name is printed as the music credit in `metadata.txt`.
- In a script: `music: calm` (a random track of that mood, the same one in draft and final), `music: track name`
  (that track), `music: calm, tense, epic` (full videos: one per chapter), `music: none` (no music). The Music tab
  in Video Studio writes this line for you and lets you listen first.

## Sound effects: `sfx/<kind>/`

| Folder | Sound | Used automatically for (`sfx: auto`) |
|---|---|---|
| `whoosh` | fast air swoosh | title cards, chapter changes |
| `riser` | rising build-up | charts, "suddenly", "surge", "soar" |
| `impact` | low hit / sub drop | "crash", "collapse", "plunge" |
| `pop` | short pop | "pop", "burst" |
| `ding` | bell / notification | big numbers |
| `cash` | cash register, coins | numbers with a currency sign |
| `typing` | keyboard | quotes, "typed", "email" |
| `click` | mouse / button click | "click", "button" |
| `shutter` | camera shutter | "photo", "camera" |
| `glitch` | digital glitch | "glitch", "hack", "error" |
| `heartbeat` | heartbeat | "fear", "panic" |
| `tick` | clock ticks | "deadline", "countdown" |
| `alert` | warning beep | "warning", "alarm" |

More kinds used by the motion-graphics scenes (2026-11-11, 8 CC0 files each where Openverse had them; see
sfx/CREDITS.md): `stamp`, `paper`, `swipe`, `bubble`, `coin`, `error`, `success`, `notification`, `swoosh-up`,
`boing`, `record-scratch`, `crowd-gasp`, `keyboard-enter`, `coin-drop`, `door`, `crowd-cheer` (only 1 so far).
Top up with `bin/python tools/fetch_sfx_openverse.py -n 8` (CC0 only). Motion videos play the files the last 5
finished videos didn't use first (data/asset_history.json).

- Each folder already has a `starter_<kind>.wav`: simple sounds generated by `tools/make_starter_sfx.py` (made
  from scratch, so no licence needed). **Any file you add to a folder is used instead of the starter one.**
  With several files in a folder, one is picked per use (the same in draft and final).
- **What I need to make them sound professional:** 1-3 real sounds per kind. The first five rows matter most.
- Keep them short: only the first 2.5 seconds of an effect are played.
- In a script: `[sfx: whoosh]` plays that kind at that point. `sfx: auto` in the header lets Video Studio place
  effects by itself (the Sound effects tab).

## Licences (important: the channel is monetised)

Only upload audio you are allowed to use in monetised videos. Safest free source: **YouTube Studio -> Audio
library** (Music and Sound effects tabs). Prefer tracks marked "No attribution required"; if a track needs
attribution, keep the artist in the file name and paste the credit line from `metadata.txt` into the video
description. This repository is private: don't make it public with other people's music in it.
